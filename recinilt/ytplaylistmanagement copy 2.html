🔑 API Ayarları

⚠️ CORS Sorunu Çözümü:
Uygulama sırayla CORSProxy.io, AllOrigins, CORS-Anywhere ve ThingProxy'yi dener.
Eğer çalışmazsa: Chrome'u --disable-web-security ile başlatın veya CORS eklentisi kurun.

📝 API Anahtarı Nasıl Alınır:
1. Google Cloud Console'a gidin
2. Yeni proje oluşturun veya mevcut projeyi seçin
3. "API'ler ve Hizmetler" → "Kütüphane" → "YouTube Data API v3" etkinleştirin
4. "Kimlik bilgileri" → "Kimlik bilgisi oluştur" → "API anahtarı" seçin
