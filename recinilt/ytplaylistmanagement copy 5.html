🔑 API Ayarları

⚠️ CORS Sorunu Çözümü:
Proxy'ler çalışmadığı için uygulama demo modda çalışacak. Gerçek veri için:
1. Chrome CORS Eklentisi: "CORS Unblock" veya "Disable CORS" kurun
2. Chrome Terminal: chrome --disable-web-security --user-data-dir=/tmp/chrome_dev
3. Localhost: Bu HTML dosyasını bir web sunucusunda çalıştırın

📝 API Anahtarı Nasıl Alınır:
1. Google Cloud Console'a gidin
2. Yeni proje oluşturun veya mevcut projeyi seçin
3. "API'ler ve Hizmetler" → "Kütüphane" → "YouTube Data API v3" etkinleştirin
4. "Kimlik bilgileri" → "Kimlik bilgisi oluştur" → "API anahtarı" seçin
